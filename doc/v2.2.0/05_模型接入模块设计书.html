模型接入模块设计书

版本：2.2.0；日期：2026年10月10日。

1 先行验证与选型

先行记录见 模型接入验证。Node 22.23.1 使用 openai 7.32.0（Apache-2.0）、jose 6.2.12（MIT）、smol-toml 1.9.1（BSD-3-Clause），均锁定依赖且禁止安装生命周期脚本。最小离线试验验证官方 SDK 的 Responses SSE、jose 签名校验、TOML 凭据往返；公开 OIDC 发现地址可达。未使用真实账户凭据或推理。

OMP 完整认证存储依赖 Bun、SQLite、账号池及工具包，且其固定 Codex 客户端身份不同于当前官方第三方 OSS 流。本版实现小型 TypeScript 适配器并复用官方 SDK，不安装整套 OMP，不复制其客户端 ID，不重写为 Go。

2 结构与公开接口

源码 src/factorforge/applications/model_access/，package.json/package-lock.json 为独立模块。api/protocol.ts 定义请求和响应；config/store.ts 负责私有 TOML 与排他锁；adapters/oauth.ts 负责官方登录/刷新/撤销；adapters/responses.ts 复用 SDK；application/service.ts 执行预算和命令；entrypoints/cli.ts 装配。测试放 tests/applications/model_access。tsc 产物输出 runtime/model-access-build，源码目录不放 dist。

启动 Node CLI，支持 status、login、logout、models、serve、unlock。serve 为逐行 JSON（stdio/JSONL），单进程顺序处理，stdout 只输出契约。请求使用 v=1、id、op（status/models/generate）、channel（api/chatgpt）；generate 另含 model、input。响应使用 v/id/ok/result 或 error.code，禁止传入凭据、URL或任意供应商参数。公开协议见 contracts/v2/model-access/protocol.json。请求与错误均不自动重放。

本模块不调用 P1/P2 接口，不直接访问它们的私有代码或数据库。现有 EvidenceExtractor、JevDecisionProvider、FrameworkClient 均不修改；未来实例客户端须只使用上述协议，抽取候选仍经过原有核验与确定性准入。

3 配置与持久状态

config/config.example.toml 末尾追加唯一标记区 BEGIN/END FACTORFORGE MODEL ACCESS，包含 [model_access] 的 enabled、api_base_url、api_key、prompt_file、timeout_seconds、login_timeout_seconds、max_input_bytes、max_output_bytes、max_line_bytes、budget_window_seconds、api_max_requests、chatgpt_max_requests、state_json。公开模板全部为空、零或 false。state_json 为模块写入的 JSON 字符串，存稳定 host_id、可选单账号 OAuth 记录与各通道窗口计数、请求标识；不存输入输出。API 与 ChatGPT 预算独立。

只接受 config/config.toml，拒绝符号链接；Unix 要求本人所有、无组/其他权限。持有同目录 .model-access.lock（wx，0600），记录 pid/hostname/随机 owner。所有操作持锁；刷新在单一进程内串行。unlock 仅在锁属本机且原 pid 已退出时删除，并核对原字节。非本机或存活 pid 需操作者调查，不按时长自动抢锁。

写入前核对原配置字节哈希。只重建自有标记区，解析新旧 TOML，断言除 model_access 外语义完全相等；保留区外原字节与注释。临时文件 0600、fsync 后原子 rename，并同步目录。配置冲突或轮换令牌写入失败阻断进一步调用；不把旧令牌继续当可用，不写第二个凭据库。正常退出按 owner 删除锁；崩溃保留锁，显式 unlock。

4 官方 ChatGPT OAuth

固定 issuer https://auth.openai.com，发现 /.well-known/openid-configuration 并要求 issuer、authorization/token/revocation/jwks 端点均在该域；禁止重定向。初始 client_id=dynamic_agent_client、agent_name_hint=Factorforge；稳定 ext_agent_host_id=urn:uuid。新登记 callback 必须给 issued client_id，不能为 dynamic_agent_client；返回登录沿用已保存 client_id，若 callback 换 ID 则拒绝。

先监听 127.0.0.1 随机端口 /auth/callback，再显示 Continue with ChatGPT URL；随机 state、nonce、PKCE S256，resource=https://api.openai.com/v1，scope=openid profile email offline_access resource.invoke chatgpt.tokens.use.direct。回调只取单值字段，校验 Host/path/state；错误回调不兑换，超时关闭 listener。运行在 Ubuntu 时由操作者使用 SSH 转发相同 loopback 端口，或在本机运行 CLI；不绑定 LAN 来规避回调协议。

兑换使用 issued client_id、code_verifier、相同 redirect_uri/resource，不使用 client secret。jose JWKS 校验签名、issuer、audience、exp、nonce、sub；返回登录 sub 必须匹配。保存 client_id、subject、id_token、access/refresh_token、token_type、expires_at、earliest_refresh_at、scopes。没有 chatgpt.tokens.use.direct 时保存身份但禁止推理。刷新使用 refresh_token grant+client_id/resource；轮换凭据整体原子保存，scope 缺失保留原授权，refresh_token 缺失保留原值。到期前不自行添加未标定刷新提前量。

invalid_grant、失效 refresh_token 等确定终态只清除匹配连接的令牌并要求登录；网络/5xx 保留凭据且返回临时失败。退出先从内存移除连接，尝试 POST 撤销 refresh_token，最后删除本地凭据，返回 remote_revocation_confirmed 布尔值；本地写失败不能宣称退出成功。

5 Responses 与模型目录

API 使用配置 HTTPS base_url；ChatGPT 固定 https://api.openai.com/v1。官方 SDK maxRetries=0，禁用日志，显式 AbortSignal 单次截止时间，fetch redirect=error。调用 responses.create，body 只含 model、input=[user]、可选私有 instructions、store=false、stream=true；不发送 OAuth 预览不支持的 temperature/max_output_tokens 等字段。模型名必须来自该通道目录；API 读取 /models data，ChatGPT 读取 models 且 visibility=list，保持目录顺序。

逐事件限制输出 UTF-8 字节，必须收到 response.completed、status=completed，并从终态 output 的 assistant message/output_text 聚合正文。refusal、其他工具输出、空结果、failed/incomplete、无 completed、HTTP/stream error 各返回明确错误，不把中间 delta 当成功。HTTP 原始 body、SDK message/stack、URL、令牌和候选正文不进入错误结果。返回请求标识、channel、model、text、供应商 response_id 和有限数值 usage；只通过调用者的私有管道返回正文。

6 预算、状态和异常

调用前校验 enabled 与全部正数边界；以持久 UTC 时间窗口按通道记录 count 和 ids。单窗口请求数与 ids 同步增长，达到已配置上限拒绝；重复 id 拒绝，不缓存正文。时钟回退拒绝；窗口到期清空该窗口 ids，契约明确去重范围限当前窗口，调用者承担跨窗口业务幂等。预算持久写成功才调用上游，故进程崩溃最多损失一个占用，不释放未知请求。

共享额度 429 subscription_sharing_usage_limit_exceeded → PLAN_USAGE_LIMIT，当前进程暂停 ChatGPT；提供 https://chatgpt.com/settings/usage。普通 429 → RATE_LIMITED，503 → PROVIDER_UNAVAILABLE，401 → AUTH_REQUIRED 或 AUTH_REJECTED，403 → PERMISSION_DENIED，400 → REQUEST_REJECTED；终态 response.failed/incomplete 单独报告。传输/超时/断流 → DELIVERY_UNKNOWN。均不自动重试，不自动转 paid API。status 仅返回配置、登录、scope/expiry、预算计数和暂停码，不返回 account sub/email、令牌或请求内容。

7 开源参考位置

OMP Auth Broker/Gateway：凭据所有者与上层调用者分离；同版本 packages/ai/src/auth/refresh.ts：单次刷新与持久化竞争处理，仅参考思想，不复制账号池、时间常数或固定客户端身份。

openai-node v7.32.0：resources/responses/responses.ts、core/streaming.ts、client.ts 的 SSE、AbortSignal、重试控制；直接依赖 SDK。jose：jwtVerify/createRemoteJWKSet；smol-toml：parse/stringify。依赖锁与许可证随源码公开。

OAuth 协议来源为 官方 OSS 登录、会话与刷新、模型调用、异常恢复及预览限制；验证日期 2026-10-10。

8 验收映射与部署

S5-001→目录/显式通道测试；S5-002→签名 OIDC 夹具、state/nonce/audience/账号不匹配、过期、取消、刷新和退出；S5-003→真实 SDK 流终态、拒绝/断流/超时；S5-004→持久预算、重复 id、额度错误无 fallback；S5-005→配置锁、冲突、原子写和隐私错误。T5-01～T5-05 用本地受控 HTTPS 语义夹具/注入 fetch 与独立原生 Node 进程验证；CI npm ci --ignore-scripts、tsc、node --test，不访问真实账户。

操作者将空模板标记区追加到真实配置，填写自己的边界与 API Key（若使用 API），再执行 login（若使用 ChatGPT）。源码 README 给完整命令。T5-06 需用户本人完成官方授权与明确选择模型，账户前置步骤完成前记录 ACCOUNT_VALIDATION_PENDING；不复用 Codex 已有凭据。新模块不启动任何 P1/P2/P3 worker 或交易请求。
