Web 管理台设计书

版本：2.14.0；日期：2026年10月23日。唯一对应《Web 管理台仕様书》。本书定义可用于生成代码的模块、DTO、接口调用、程序控制流、开源复用与验证。状态“现有”以本仓库提交 85581bf2d63775ed7f6eb2325f8723c213ac5453 的 OpenAPI 和源码核对；本书所有 console/P3 接口及明确新增的 P2 查询均为待实现，不代表已有服务器。

1 技术选型、目录和职责

采用 React + TypeScript + Vite、TanStack Router/Query/Table 与 shadcn/ui 组成浏览器管理台；金融图表使用 Lightweight Charts v5 的公开 API。只裁剪复用上游布局和通用组件，不引入整套交易后台或云端 Clerk 认证。实际实现时固定 npm 版本和锁文件，不能把上游 main/master 当作构建依赖。

2 会话、身份和绑定

ConsolePrincipal={user_id, deployment_ids, environments, instance_ids, capabilities:[view,export]} 是管理台身份，不能转换为 WorkloadIdentity。下层公共 principal/token 按服务、环境和实例分配，策略仅授予 ApiScope.QUERY，交易层仅使用读权限。console 的 HTTP transport 按“服务 + 方法 + 固定路由模板”白名单发请求，不允许用户提供 URL、任意代理路径、账户或令牌。

绑定 SelectionBinding={deployment_id,environment,instance_id,object_id,trading_run_key,instrument_key,owner_id,binding_version} 在服务端由私有登记及允许的对象查询交叉验证。URL 中 selection_id 仅是不可提升权限的选择标识。对象所属环境/实例、产品和交易运行不匹配返回 BINDING_MISMATCH；无对象时可查看允许的交易运行，框架面板标注不适用，而不是创建对象。

本地登录采用服务端密码哈希验证和随机不透明会话标识；只在私有 config/config.toml 登记用户名、哈希与授权绑定。原始密码、哈希、服务 token 都不写入前端或日志。会话 cookie 使用 HttpOnly、Secure、SameSite=Strict，局域网正式部署采用受信任 HTTPS；不提供降级为浏览器持久保存下层 bearer 的方案。登录和退出校验 Origin/CSRF，配置限流、会话期限和撤销，未知配置不能开放访问。登录页先调用 GET /session/challenge 取得与短期 HttpOnly 预会话 cookie 绑定的随机 csrf；POST /session 校验 Origin、预会话及 csrf 后销毁该挑战并换发新会话，失败重取挑战。登录成功响应仅向当前同源页面提供新的会话 csrf，退出使用 X-CSRF-Token 校验；CSRF 值只驻留内存，不写日志或浏览器持久存储。挑战期限、限流和会话期限由私有部署配置给出，不在本设计中填入生产常数。

挑战和登录之外的请求先验证会话；session、selections 与不带选择的 capabilities 只返回当前用户授权范围，不要求用户尚未取得的 selection_id。业务查询及导出则同时核验选择绑定，capabilities 带 selection_id 时也核验绑定。退出和401清空 Query 缓存；403清空被撤权选择的数据；302/前端路由守卫只负责体验，不能替代服务端授权。响应 Cache-Control:no-store，不注册缓存私有数据的 service worker。原文显示使用 textContent/React 文本或经过允许列表净化的安全片段，禁用任意远端 HTML、图片跟踪或 iframe。

7 数据模型、字段映射与查询组合

ReadSection<T>={state:AVAILABLE|EMPTY|STALE|UNAVAILABLE|FORBIDDEN|NOT_IMPLEMENTED|NOT_CONFIGURED|NOT_APPLICABLE,data:T|null,source,observed_at:UTC|null,fetched_at:UTC,snapshot_version:string|null,binding_version,reason_codes,correlation_id}。取数成功但业务质量陈旧使用STALE；失联已有缓存时data保留旧值，state为STALE并附UPSTREAM_UNAVAILABLE。真正空结果为EMPTY，禁止、撤权和跨选择数据一律清除。

Overview先核验SelectionBinding，然后并发读取P1账户/仓位/保护/运行、P2对象/pool/最新决策与可选P3健康。采用独立超时和预算，单源失败不把其他面板一并清空。每个子区保留原始数据时间；source缺少observed_at时填null，不能用fetched_at冒充事实时间，也不能把多服务组合标为一个原子快照。

表格与金额保留JSON中的Decimal字符串及货币/数量单位。精确比较采用十进制库；仅图表显示坐标在检查有限值和范围后转number，tooltip仍显示原字符串。不得在浏览器重新实现pool、decay、目标或账务公式。病例、订单和目标关联以object_id/owner_id/instrument_key/decision_id/target_version/owner_epoch/fill_ids等实际标识为准；缺少字段停止推断。

现有P2全量列表由BFF先按授权对象筛选，时间或排序只对已取得范围生效；预算不足拒绝大范围请求。新增ReadPage支持持久快照版本与稳定游标，不可把当前全量数组描绘成数据库分页已完成。缓存键完整包含用户、部署、环境、实例、object_id、binding_version、时间窗口；服务端缓存同样隔离，不共享原文或授权结果。

8 路由、组件和图表程序逻辑

路由为 /overview,/market,/events,/events/$eventId,/sentiment,/decisions,/execution,/cases,/cases/$caseId,/learning,/operations,/reports。SelectionProvider持有binding与generation；环境/实例/对象切换时递增generation、abort全部旧请求、移除旧选择缓存并重置详情。响应必须匹配generation和binding_version才可写入。路由search schema对白名单时间/枚举/分页进行验证，不允许token或raw证据进入URL。

api/console-client.ts只调用console同源接口，统一错误DTO和AbortSignal。features内以queryOptions组织读查询；设定可配置刷新间隔、单源超时和最大重试，首期使用HTTP轮询，不设计一个实际上未存在的WebSocket/SSE。后台页暂停高频刷新，回前台先验证会话再刷新；所有重试仅对允许GET生效。401终止并退出，403清空受限数据，409重取能力/绑定/快照，422显示过滤错误，429遵守Retry-After，网络/5xx有限指数退避并标明旧值；retryable=false不自动重试。

components包括ApplicationShell、SelectionBanner、ReadSectionPanel、StatusBadge、VersionTimeline、SourceTime、DecimalValue、DataTable和EvidenceViewer。业务专属EventDetail、ContributionLedger、TargetExecutionCompare、CaseObservation、LearningTimeline分别实现，不套用模板的编辑/批量删除。列表无同名事件或状态的假设；表格row ID用稳定来源标识。

行情组件mount时 createChart、chart.addSeries(CandlestickSeries)、series.setData；时间采用UTC秒并按open_at升序去重，缺口留空不插值。变更窗口按实际历史重载；最终K线更新用 series.update，不伪造当前未闭合K线。实际成交与事件生效用 createSeriesMarkers；通过稳定ID映射详情，密集标记聚合为可展开数量，不隐藏修订关系。

价格线采用 createPriceLine 显示已核验保护触发价、实际平均价；标记用途、版本和时间，失效保护不能保持为当前有效线。清理时detach markers、remove chart、移除ResizeObserver和轮询；iframe/外部行情网站不能代替P1数据。启用attributionLogo并保留NOTICE文字/链接。

9 明确拒绝的调用与私有字段

HTTP allowlist不包含P1任何POST/PUT/PATCH/DELETE业务接口（orders/cancel、protections、owner targets、runs动作、simulation frames、external-facts/fx/market snapshots/fence等）。不包含P2创建对象、修改对象state、创建/修订事件、提交/修订评分、attribution-candidates或clock；不连接内部workload listener。console POST/DELETE只用于自己的登录退出。浏览器不执行交易，也没有给研究请求升级交易资格的入口。

禁止输出command_payload、真实Prompt片段、供应商完整请求、服务token、数据库DSN和私有资产路径。input_snapshot、manifest/result、audit.detail等自由字典必须用显式只读DTO提取已定义字段；不能依赖“名字像secret才删”的递归黑名单。发生上游格式变化时拒绝对应子区并记录公开错误码，不将整个未知字典交给浏览器。

Go 迁移共同约束与切换门槛

语言选择按模块而非全项目统一：现有 P1/P2 与已实现上层 Go 模块继续采用 Go；上层可复用 TypeScript/JavaScript 等非 Python 模块，不要求为统一语言重写成熟接入代码。语言选择不改变三层依赖、公开契约、权限隔离或准入；Python 不得作为活跃源码、解释器、子进程、HTTP 服务或构建/测试/hooks/CI 的必需依赖。具体跨语言传输和模块引入仍须先验证再定稿设计。根 go.mod 是本仓库 Go 模块唯一真源，只约束 Go 源码，go.sum 固定其依赖校验；现有工具链 Go 1.27.1。Go 生产代码仍只放 src/factorforge 对应层，domain、application、ports、adapters、api、workers 六类职责保留；独立 main 放本层 entrypoints/入口名。P1 不导入上层，P2 仅引用 P1 api/dto 的公开值类型和 HTTP 客户端；不创建承载跨层业务的 common。Go 测试放 tests 对应层，数据库迁移仍归属本层 PostgreSQL 适配器。

新实现不调用 Python 子进程、不嵌 Python 解释器，也不以 Python HTTP 服务作为最终 Go 后端。迁移期间旧源码与入口保留，用合成夹具捕获对照；不得双启动同一账户的执行者、双写同一运行，或因 Go 模块编译通过就替换运行服务。切换前记录当前版本、运行状态和库快照，停止旧执行者并取得隔离证据，由新进程恢复对账；回退也须停止并隔离新执行者，不能同时使用同一签名身份。

替换全部活跃初始化、布局/版本/HTML/公开内容/历史契约检查、构建、hooks、CI 与运行工具；最终用没有 Python 的受控环境完成 Go 构建、单元/故障/真实 PostgreSQL/独立进程/SIM 验收。历史冻结文档中的 Python 文字或文件保留为历史，不要求运行其作者脚本；旧活跃作者工具在 Go 替代检查通过后退役。迁移夹具 JSON 自带源提交和 fixture_only，Go 测试读取固定结果，不依赖即时 Python oracle。真实配置及 Prompt 不迁移进夹具。

16.4 隧道部署（S4-018）

  • 配置 [console] 新增 trusted_peers（IP 或 CIDR 列表，默认空）。非空时，api.New 外层先检查 RemoteAddr：本机回环或在列表内才继续，否则返回 PEER_FORBIDDEN（403）且不读会话；来自列表内主机的请求还必须 Host 等于 origin 的主机名，否则 HOST_FORBIDDEN（403）。为空时行为与旧版相同。
  • origin 登记公开地址（如 https://<登记域名>），cookie 仍为 __Host-、Secure、SameSite=Strict。console 自身以 TLS 监听局域网地址，证书为部署私有自签证书；隧道端连接 console 的 HTTPS 源站。边缘按邮箱白名单认证，隧道令牌与边缘规则只在隧道所在设备与边缘服务中，不进仓库。限流与挑战按 RemoteAddr 计数，经隧道时即按隧道主机合并计数，属已知限度。
  • 下层 P1/P2/P3 仍只监听本机；console 访问它们须为 HTTPS，由本机 TLS 代理提供，所信任的私有 CA 由部署环境变量 SSL_CERT_FILE 指定。每个对象绑定需要该实例的 P2 公共读取监听（PUBLIC_RESEARCH）与 P3 只读 API。

17 v2.11.0 实时参考行情

唯一对应式样 S4-019。会话、权限、绑定、账本区块的读取与刷新沿用第 2～8 章和第 16 章，不新增写入路径，也不新增下层调用。上游是交易所公开行情，不需要账户凭据。

17.1 上游订阅

  • 新文件 adapters/market_stream.go，使用仓库已有依赖 golang.org/x/net/websocket 的客户端（不新增依赖），收到 ping 时由该库自动回 pong。订阅地址为 {live_market.url}/market/stream?streams={s}@markPrice@1s/{s}@kline_{interval}，其中 s 是绑定 instrument_id 的小写形式。2026-10-17 先行验证：/market/ 路径下标记价每秒 1 条、K 线约每 250 毫秒 1 条；旧路径 /stream 与 /public/ 能建立连接，但收不到这两类数据。
  • 解析两类消息：markPriceUpdate 取 s、E（毫秒）、p；kline 取 k.t、k.T、o、h、l、c、x。价格保留十进制字符串，并要求是正的有限数。标的不符、字段缺失或格式不符的消息丢弃并计数，不中断连接。
  • 每次读取设 30 秒期限；超时或出错即断开，按 1、2、4…最多 30 秒退避重连。连接满 23 小时主动重建，避开交易所 24 小时的连接上限。

17.2 共享与分发

  • 新文件 application/live_hub.go，LiveHub 按（venue、product、instrument、interval）共享一条上游连接：第一个订阅者到达时建立，最后一个离开 idle_seconds 后关闭。Hub 保存最新的一条标记价和一根 K 线，新订阅者立即收到这份快照。
  • 每个订阅者只有容量为 1 的“最新值”槽：慢的浏览器只会丢掉旧帧，不会阻塞上游或其他订阅者。
  • 状态：CONNECTING（尚未收到数据）、LIVE、STALE（stale_seconds 内没有新消息）、UNAVAILABLE（连接失败，附代码 LIVE_UPSTREAM_UNAVAILABLE）。

17.3 浏览器推送接口

  • GET /api/v2/console/live?selection_id=，返回 text/event-stream（SSE）。用 SSE 而不是浏览器 WebSocket：只需服务端单向推送，可沿用同源会话 cookie 与 Sec-Fetch-Site 检查，浏览器的 EventSource 自带断线重连，不需要新增前端库，CSP 的 connect-src 'self' 也不用改。
  • 授权和其他 GET 相同：会话有效，且所选范围属于该用户。未启用参考层或绑定不适用（当前只适用于 venue=BINANCE 且 product=LINEAR_PERPETUAL）返回 LIVE_NOT_APPLICABLE（404）；同时打开的流超过 max_streams 返回 LIVE_STREAM_BUDGET（429）。
  • 事件：event: mark，数据为 {"at","price"}；event: kline，数据为 {"open_at","close_at","open","high","low","close","final"}；event: state，数据为 {"state","at","code"}，状态变化时发送，并兼作心跳，每 heartbeat_seconds 一次；event: end 表示服务端结束推送。时间均为 UTC RFC 3339。
  • 服务器的全局 WriteTimeout 会切断长连接，因此每次写入前用 http.ResponseController.SetWriteDeadline 单独延长写期限，写完立即 Flush。每次心跳都重新校验会话（Sessions.Current）；会话失效、退出或撤权时发送 end 并关闭。请求取消（浏览器关页）时退订。
  • 路径登记进 api/openapi.go，由 export-console-contract 导出到 contracts/v2/console/openapi.json。

17.4 配置

[console.live_market]：enabled（默认 false）、url（交易所公开行情推送的根地址，必须是 wss://）、interval（与本页 K 线一致，5m）、stale_seconds、heartbeat_seconds、idle_seconds、max_streams。enabled=false 时与 v2.10.0 行为相同。模板与 tools/repoguard 的空模板核对同步增加该块；旧的派生配置缺这一块时按未启用处理。

17.5 浏览器页面

  • 新文件 web/src/features/live-market.ts：useLiveMarket(selection) 只在页面可见时打开 EventSource，页面隐藏或切换范围时关闭；收到 end 后不再重连。
  • dynamic-page.tsx：新增“参考标记价”与“参考浮动盈亏（约 R）”两张卡片，标明“参考 · 交易所公开行情”及状态和时间；STALE 时变灰，UNAVAILABLE 时显示原因。止损梯增加“参考标记价”一行和“相对参考”一列。参考浮盈用 P1 仓位数量与均价，在浏览器内按显示值换算，不当作账务。
  • market-chart.tsx：新增可选的 live 参数（正在形成的 K 线）。用单独的 effect 调用 series.update() 只更新最后一根，不重建图表；颜色半透明。它的开盘时间不晚于最后一根最终 K 线时不画。

17.6 部署

经隧道访问时，边缘对 text/event-stream 不做缓冲；15 秒的心跳低于边缘的空闲超时。影子 E15 的部署配置启用参考层，并把 refresh_seconds 改为 15，让账本数字在 P1 更新后更快读到（P1 本身仍约每 60 秒更新）。
