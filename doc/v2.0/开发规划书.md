# Factorforge v2.0 开发规划书

版本：2.0；日期：2026年10月4日。用于持续AI开发保持方向；功能看对应式样书，代码实现看对应设计书。

## 阶段顺序与完成条件

| 阶段 | 应完成的事情 | 完成条件 |
| --- | --- | --- |
| P1 交易系统层 | 建立独立交易包、接口与配置；完成行情、模拟执行、实盘适配方向、保护、账户风险、幂等及恢复 | 上层未安装时T1适用验收通过；实盘未验证能力明确未就绪 |
| P2 策略化框架层 | 创建对象/事件/评分；完成情绪、兑现、仓位、止损计算、案例、归因、反事实及固定步长学习 | 不安装应用层，以手工/夹具完成T2闭环，底层拒绝不能被绕过 |
| P3 SOXLUSDT/JEV实例 | 完成监控、搜索、证据抽取、路由、JEV映射、框架提交及实例配置 | T3离线/联调通过；真实供应商、来源许可和未决配置有独立验证记录 |
| P4 理论与实时验证 | 标定最少参数，完成无泄漏研究、前瞻影子、模拟及故障恢复；取得日亏损与双次数默认值证据 | 核心假设、样本外/前瞻证据及适用安全验收满足R0～R2准入；不足就停止升级 |
| P5 有限实盘与交付 | 关闭目标账户、DEC-06、预算和人工预案等阻塞；在另行授权下进行400 USDT上限实盘，完成运维及脱敏成果 | R3适用证据齐全；代码/文档/验收可追踪；公开发布及扩额各有授权 |

## 每次继续开发

只记录当前阶段、已完成需求及其证据、未完成需求、阻塞项和下一件工作。先完成下层再启用上层；阶段内可做不依赖阻塞项的工作。完成代码不等于业务验证通过，不因盈利自动升级。

本次已完成版本归档及v2.0文档基线，代码开发从P1开始。此规划不拆成大量工作包，不重新定义需求或填写待标定常数。
