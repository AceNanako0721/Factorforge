# v1.1 需求迁移与待决事项

版本：2.0；日期：2026年10月4日。本表追踪历史规则的归属，不向开发规划复制详细工作包。新版式样编号S1/S2/S3及验收编号T1/T2/T3是当前真源，旧编号只用于迁移。

## 1 保留及结构变更

v1.1 的需求和质量要求全部有新版落点。数学、事件修订、守恒、风险优先、固定步长门控与自动生效保留；目标/模型/搜索属于应用，确定性量化属于框架，执行/最终账户风控属于交易。旧规划的估算人日和大量工作包不作为新版工程顺序，改以P1～P5管理，历史任务去向列在下表。

原两层Core/Upper以及“JEV在Core内部”的结构被本次三层要求取代。交易信号资格仍由框架服务独立核验，但评分worker和Provider运行在应用层。允许从已有事件提交评分或修订；事件创建不自动注入。该结构变更是本次用户要求，不能据旧结构阻止应用提交评分。
