1 范围与继承

本模块与 SOXLUSDT/JEV 实例及 Web 管理台同属第三层，可独立启动。提供 API Key、订阅登录、凭据刷新、模型发现与文本生成。此次把 OMP 固定版本的全部登录入口与相应模型接入能力纳入模块；登录成功后，程序可以使用该连接调用模型并向上层返回结果。原有 API / 官方动态 ChatGPT 两条连接仍可使用。

模型输出仍是未核验候选文本，不授予事实、事件、评分或交易资格。JEV 固定决策通道保持；暂停的抽取试验及本地模型不启动。本模块没有文件、命令执行、交易、后台代理或自主工具循环权限。

2 S5-001 / S5-008 通道、账户与模型

保留原有 API / ChatGPT 通道。新增 OMP 通道覆盖所采用上游版本注册表中的全部登录方式，包括 ChatGPT/Codex、Claude/Anthropic、Antigravity 及其他供应商的 OAuth、设备码、浏览器会话与 API Key 入口。入口随锁定版本登记，不以三个占位按钮代替。搜索等工具凭据可以登录和退出，但须明确显示用途，不能冒充文本模型通道。

每次模型调用显式选择供应商、本地账户句柄与模型，不自动切换账号、供应商、订阅或付费 API。支持多个连接；本地句柄只用于选择，不暴露邮箱、供应商账号 ID 或令牌。登录入口别名与它实际保存的供应商关系可见。

模型目录注明来源：当前供应商发现、缓存或上游内置目录。内置/缓存目录不能被称为账户授权验证通过。对于提供账户限定目录的通道，发现失败不能据此声称账号可用；模型最终资格由实际调用结果确认。没有模型能力的凭据显示清楚原因。

3 S5-002 / S5-009 登录、刷新与退出

原有官方动态 ChatGPT 流保留原身份、计划权限检查和退出撤销语义。新增 OMP 流完整使用对应供应商的登录过程，不再把进入另一个 CLI 当成完成模型接入。用户可打开认证网址、完成设备码/授权码回填、填写隐藏的 API Key 或使用独立浏览器会话。程序不代填密码，不扫描或导入已有 OMP/Codex/Claude/Antigravity 凭据。

登录可取消、超时或失败；未完成的新登录不能删除原有效连接。授权步骤与必要说明只在操作者终端显示；远程终端可见可复制网址及上游回填说明。浏览器会话需要可显示浏览器，缺少环境时明确提示，不静默卡住。

保存成功才显示连接已保存；不自动发送模型测试。凭据可在重启后继续使用，并按照供应商协议刷新。同一令牌只允许一次并发刷新；持久化失败后停止后续调用。退出必须选择账户并确认，删除对应本地凭据；OMP 通道未提供远端撤销确认时明确显示“本地已删除，远端撤销未确认”。不删除其他账户或原 API Key。

4 S5-006 交互式终端菜单

复用 OMP 原版供应商选择器、登录对话与模型选择组件，支持方向键、搜索、Enter、Esc、Ctrl+C、窄屏和窗口缩放。首页提供完整 OMP 登录、连接/模型选择、退出连接、本地预算状态与显式调用测试；保留旧通道菜单入口。显示已选择的供应商、账户句柄、模型及目录来源。选择本身不暗改后台模型或发送请求。

显式测试需再次确认将占用本地和供应商额度，输入与完整结果只显示在操作者终端。非 TTY 明确拒绝菜单；机器接口不混入颜色、菜单、认证网址或调试日志。正常退出、异常、中断和 EOF 恢复终端及释放写锁。缺少运行时/浏览器时给出可执行的准备说明。

5 S5-003 / S5-004 文本调用、预算与异常

上层通过独立公开接口提交唯一请求 ID、供应商、账户句柄、模型和文本；私有提示词由本模块读取。只返回供应商明确成功结束的完整纯文本及有限数值使用量。拒绝、工具调用、空结果、不完整、断流、超时和失败分别处理，中间片段不能作为成功结果。

原两通道预算保持；OMP 采用按供应商及账户的持久次数/窗口预算。总开关、单次时间、输入输出、请求行和次数边界未填写时禁止推理。登录和只读本地状态不要求启用推理；发现目录需要配置操作超时。界面可显式填写调用边界，不能预填未标定容量。

调用前持久占用预算，错误不退占用；当前窗口重复 ID 不再次发送，时钟回退拒绝。窗口外业务幂等由调用者负责。本地预算不表示供应商剩余额度。供应商额度或限流拒绝暂停对应账户在当前进程的后续生成，重新启动仍受持久预算限制；操作者明确重试才重新确认上游状态。网络或断流可能已计费，报告投递不确定，不自动重试生成、重登录或转其他账号。

6 S5-005 私有资产与隔离

Factorforge 自主管理的全部配置与 OMP Key/OAuth 状态统一保存于被忽略的 config/config.toml；不另建凭据库。真实提示词保留私有文件，两个目录各只公开一个空模板。既有原版官方 CLI 自有凭据继续由原程序管理，本模块不导入它们。

同一配置仅一个写进程；外部改动返回冲突，不能覆盖。状态、错误、文档、测试报告与常规日志不含凭据、认证参数、真实提示词及请求/响应正文。授权网址仅显示给正在登录的操作者，不进入机器输出或日志。各层通过公开接口协作，本模块不访问 P1/P2 私有实现或数据库，不启动交易。
