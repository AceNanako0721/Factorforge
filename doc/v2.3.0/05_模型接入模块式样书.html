模型接入模块式样书

版本：2.3.0；日期：2026年10月10日。

1 范围与职责

本模块与 SOXLUSDT/JEV 实例、Web 管理台同属第三层，可独立启动。为上层提供模型连接、模型目录和文本生成能力，首批支持 OpenAI API Key 与官方 Continue with ChatGPT 登录；支持显式登记的 OpenAI Responses 兼容 HTTPS API。另外提供原版 Claude Code 与 Antigravity CLI 的操作者登录入口；用户在官方终端完成授权，退出后返回菜单。本版不将其订阅凭据导入本模块，也不新增这两家的 JSONL 订阅推理通道。

模型输出始终是未核验候选文本。接入成功不授予事实、事件、矢量评分或交易信号资格。JEV 固定决策通道不被替换；不自动挂入暂停的文本抽取链路，不启动本地模型。管理台仍只读，账户操作先由独立操作者入口完成。

2 S5-001 通道与模型选择

每次调用明确选择 API 或 ChatGPT 通道及模型，不自动选择、切换账号、转用付费 API 或改写模型。可查看连接是否配置、登录是否有效、计划调用权限是否授权，以及所选通道的可用模型目录。模型目录以供应商当前账户返回为准，不内置生产模型名称。

3 S5-002 官方登录与退出

用户在官方浏览器页面授权 Factorforge，程序不收集密码，不借用已安装 Codex/OMP 的客户端身份或凭据。登录可取消或超时，失败不能覆盖原有效连接。首次登记保留本机稳定标识及颁发的应用身份，返回登录须验证为原账号。首版只维护一个 ChatGPT 连接；更换账号先退出再重新登记。

验证账号身份与计划调用权限后才启用模型调用。令牌可在重启后使用并按官方协议刷新。退出删除本地登录凭据并尝试远端撤销；撤销未确认时明确告知。API Key 不因 ChatGPT 退出被删除。

4 S5-003 文本请求与完整结果

上层提交唯一请求标识、通道、模型及输入。真实提示词从私有文件加载。只在供应商明确结束且成功时返回完整候选文本、模型及使用量；断流、失败、不完整、拒绝、超时必须独立报告，已收到的片段不能当成成功结果。首版为文本请求，不开放外部工具、文件、后台代理或自主循环。

5 S5-004 额度与投递不确定性

本地每通道设置调用次数/窗口、单次时间及输入输出边界；未配置不能调用。不将本地预算显示为供应商剩余额度。调用前占用预算，错误与超时不退回占用；窗口内重复请求标识不重新发送。超过本地预算暂停，供应商报告 ChatGPT 共享额度不足时暂停该通道在当前进程中的后续调用并提供官方用量页面。重启后仍受持久本地预算限制，供应商是否恢复由操作者明确重试确认。

网络异常、超时或断流可能已经消耗供应商额度，标为投递不确定，不自动重试。明确的协议拒绝不标成模型成功；不自动重新登录、切换付费通道或创建交易事件。

6 S5-005 私有资产与运行隔离

Factorforge 自主管理的真实配置、API Key、ChatGPT OAuth 登录状态只存于私有 config/config.toml；原版官方 CLI 的登录凭据由其私有目录或系统钥匙串管理，不读取、复制进仓库或纳入 Git；真实提示词只存私有提示词文件。公共仓库只保留各一个空模板。状态查询、错误、常规日志与审阅产物不含令牌、提示词、输入输出正文或认证回调参数。

同一配置只允许一个模型模块进程持有写锁。并发刷新不得重复消费轮换令牌，外部配置改动必须报告冲突而非覆盖。退出、崩溃、失效凭据均可得到明确恢复指引。上层通过约定接口调用，不能读取该模块私有凭据状态。

7 验收与待确认

T5-01 两条通道分别测试，不发生隐式付费切换；T5-02 本地官方协议夹具覆盖回调攻击、身份不匹配、令牌轮换和退出；T5-03 完整流、拒绝、断流、超时与额度失败分类正确；T5-04 并发/重启预算与配置写入安全；T5-05 原生独立进程接口验证及桌面/窄屏文档检查；T5-06 用户完成官方浏览器授权后验证账户模型目录和一次获授权的非交易调用。

本地机制通过不替代 T5-06。真实账号计划资格、供应商模型和容量不预填。事件抽取方案仍由用户参与决策。

8 S5-006 交互菜单

操作者可在终端使用方向键选择、输入搜索过滤、Enter 确认、Esc 返回及 Ctrl+C 退出。支持中文、宽字符、长模型名称和小窗口，选中项保持可见；无匹配时明确提示。窗口缩放重绘，正常退出、异常和中断恢复终端。非交互管道明确拒绝菜单，原有机器 JSONL 输出不混入颜色或菜单。

菜单展示连接状态、ChatGPT/Claude/Antigravity 登录入口、模型目录、当前会话通道/模型、本地预算及退出登录。模型选择仅供本次操作者会话，不暗改后台配置或自动发送测试请求；本地计数不冒充供应商剩余额度。ChatGPT 登录显示官方 URL 与远程回调说明，Esc 可取消并保留原有效连接。退出登录须明确选择和确认。API Key 保持由私有配置管理，不在菜单回显或另存。

9 S5-007 原版官方终端登录

Claude 登录交给原版 Claude Code，官方程序负责浏览器授权、刷新和存储；可通过官方只读状态接口得到登录与认证方式，菜单不展示邮箱、账号ID或令牌。退出也由官方命令执行。

Antigravity 登录与账户管理交给原版官方 CLI，用户在该终端完成浏览器授权或远程授权码回填；用官方退出指令返回菜单。没有稳定的官方只读登录状态接口时显示“由官方终端确认”，不得根据可执行文件存在、进程退出码或模型目录推断已登录。官方退出登录在原生终端操作，返回后仍不臆测远端撤销状态。

官方终端使用独立工作目录；交接时恢复常规终端输入，返回后恢复菜单。子进程不继承模型 API Key、外部账单路由、交易凭据等环境覆盖。菜单不绕过 CLI 自身的确认、权限或账号选择，不接管 Claude/Antigravity 的订阅令牌，不把它们传给 P1/P2/P3。缺少或不受支持的 CLI 版本时给出明确安装/配置说明，禁止改用其他账号或付费 API。

T5-07：搜索、键盘、无匹配、窄窗口/中文、缩放、非TTY拒绝与退出恢复；T5-08：取消授权关闭回调并保持旧连接；T5-09：三种入口分发、官方子进程交接/失败/状态脱敏、凭据不导入；T5-10：旧配置兼容、公开模板空值、凭据路径提交拒绝。真实三家账户授权与登录后可用性分别记录，夹具不能代替账号验收。
