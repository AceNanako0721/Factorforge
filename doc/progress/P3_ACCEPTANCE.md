# P3 验收范围对照

更新：2026-10-09；v2.1.7。判定依据是当前规划和 S3/T3，不把本地机制通过、真实单次探针、生产运行及 LIVE 准入合并成一个“完成”。P3 整体验收仍未通过。

| 验收 | 已取得证据 | 尚缺的实际证据 |
| --- | --- | --- |
| T3-01 空配置启动与绑定 | bootstrap/产品快照、对象 HTTP 创建及环境拒绝的本地集成 | 目标 SOXLUSDT 产品/账户/有效生产资产联合验证 |
| T3-02 监控、搜索与原文 | RSS/受限 Fetcher、搜索备用/缓存/额度、原生进程、真实 Fed feed 与原文；审阅跨度编译、绑定只读导出及完整字节映射的离线审阅页 | 半导体/公司/宏观来源组合的适用许可、召回/新鲜度与完整性；真实首发验证 |
| T3-03 转载、修订及重复 | 实际 P2 创建/修订/重评/撤销 HTTP、幂等及审阅后独立 manifest | 从未见原文自动识别语义事件/关系的独立保留集；机械目录命中不代替此证据 |
| T3-04 JEV 弃权与矛盾 | 封闭协议/模型漂移/漏题/错值/不支持事实拒绝；基本真实探针和12例开发对照 | 适用业务量表/标定及独立评分评测；开发标签不算独立盲标 |
| T3-05 研究洪泛及保留容量 | PostgreSQL 物理队列、角色/RLS、并发/积压/预算与本地反例 | 本账户共享上游的跨实例/研究-SIM-LIVE负载、延迟及保留容量 OD-02 |
| T3-06 来源/模型故障与恢复 | 不重问未知投递、到期阻断、来源结果保留、错误投影、重启与持久额度；审阅不改旧失败 | 真实长期供应商故障/恢复及源质量记录；实际业务实例尚未启用 |
| T3-07 产品账务及参考价 | 产品/标的快照校验、代理/失效参考价反例与下层账务机制 | 目标产品实际能力、来源和账务字段的联合验证 |
| T3-08 日历、DST及双次数 | 本地日历→真实 P2 API登记；跨午夜/DST/提前收市、持久次数和禁增险/允许减险 | 目标市场有效日历与实时窗口证据，不能将夹具节假日作为生产日历 |
| T3-09 额度/保护/不自动扩额 | bootstrap阶段与名义上限、模拟/LIVE拒绝及下层保护反例 | 目标账户与业务参数的4000/400适用验证；实际交易另行授权 |
| T3-10 未定风险阻断 | 缺生产参数/DEC-06时保持不准入，当前 worker 仅支持SIM R0～R2 | DEC-06的用户风险决策和适用标定；属于P4/P5，不擅自填写 |
| T3-11 离线用户及报告 | P2学习/参数自动机制、实例一致快照、周期一次报告、管理台有限追溯 | 前瞻实时案例/参数效果；机制通过不代表研究假设成立 |
| T3-12 评测不足不越级 | 开发试验、未知成本/完整性记录、固定模型/时间及当前隔离门 | 独立盲标、领域量表、知识污染排除；正式标定/前瞻属P4 |
| T3-13 私有资产及发布 | Prompt缺失/许可拒绝、实际暂存/可达历史扫描及公开空模板 | 已审阅的生产私有资产与来源政策；不把实验Prompt安装为生产 |
| T3-14 故障残仓与恢复 | 下层故障阻断、外部事实导入和既有人工恢复预案记录 | 目标账户官方操作/备用访问/人员及实际演练；实盘前独立复核 |
| T3-15 实例只读 | 八类GET/封闭DTO、权限/许可/分页、真实PostgreSQL和原生API重启、读前后状态保持 | 生产实例事实需实际实例运行；Mock投影不能称其正在运行 |

Web 管理台 T4 的实现/本地浏览器/CI证据见 [P4 历史管理台记录](P4.md)，不等于规划的 P4 理论验证已完成。

下一项自主工作是冻结有许可的业务样本与独立标签流程、验证语义抽取及事件关系，再先修订配对设计、后实施自动化。实际来源首发/映射、账单和共享容量继续取证；不需要用户为每个实验参数填写生产值。真正涉及开支上限、账户专属资料、DEC-06与实盘授权、人工应急及独立人员安排时，才要求用户参与。当前不启动实际业务实例，不发起真实交易。

详细实测见 [P3进度](P3.md)、[抽取方法试验](../engineering/P3_EXTRACTION_EVALUATION.md) 和 [真实来源验证](../engineering/P3_SOURCE_VERIFICATION.md)。
