# Go 迁移进度

目标：后端及活跃工具全部移除 Python；React/TypeScript 编译为浏览器 JavaScript。业务式样、三层职责、HTTP/状态/权限语义保持。开发基线 v2.1.1，原实现对照是 v2.1.0 标签提交 `e97c9e9a380d105a7e96933bdd325e1d9af06d93`。

## 已开始落地

- 四组 HTML 设计同步调整 Go 包、入口、实际下层接口、参考、异常与切换；四本式样只更新版本元信息，正文语义保持。
- 根 go.mod/go.sum，Go 1.27.1，固定 apd/v3 v3.2.3，没有跨层业务 common。
- P1：不可变有限十进制/JSON 字符串、28 位运算和数量趋零舍入、执行租约/隔离/epoch、公开 DTO 值接口；原完整交易状态类型、字段/跨字段约束、保留接收顺序的事实集合；账务/多币种/风险/保护/外部事实及完整 SIM Broker 方法与撮合。事务副本在校验或算术失败时不提交；HTTP 必需字段存在性、null/default 和 UTC 入站规范化尚待迁移。
- P2：40 位衰减、逐贡献账本、共同价格兑现、守恒/时钟失败不提交、滞回、数量/组合投影、已有风险缩放、噪声止损/实际保护减险、公共/工作负载独立身份类型。
- 固定 JSON 对照 386 组，来自原业务函数；Go 测试不运行 Python、不读配置、不访问交易所。
- P1 固定交易对照 114 条连续轨迹、954 步，逐步重建并比较整个账户状态、返回事实及错误码。包括部分成交、成本、重复/冲突事实、资金收入、保守/拒绝 OHLC、限价排队/IOC/POST_ONLY、共同流动性、延迟/参与率、影子、强平残仓、外部所有权恢复、多币种、组合方向/分组/压力、SIM/LIVE 保护替换。夹具来自冻结 v2.1.0，仅使用合成账户/标的/政策；源提交记录为实际 commit，不是 annotated tag 对象。
- Go AST 源码/依赖检查；迁移期 Python guard 同时检查 Go，最终切换时退役旧入口。
