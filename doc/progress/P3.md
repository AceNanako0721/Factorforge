## S3-018：实例只读基础已实现，本地验收通过

八类 GET、显式 DTO/OpenAPI、完整只读权限与环境/实例绑定、签名分页/筛选、记录及字节预算、未知/缺失事实和受限原文投影已实现。API 没有框架写入、交易、供应商调用或任务升级入口。研究与当前环境任务分区读取，另一环境不能混入实际任务或预算数据。读模型只反映已经保存的状态，不模拟工作进程正在运行。

验证包括实际 HTTP 成功响应的契约校验、非法参数、空/重复参数、UTC、越权及许可、原文哈希、伪造/过期/范围变化游标、未知记录和完整状态保持。临时真实 PostgreSQL 验证 SIM/LIVE、RLS 跨实例隔离、只读 SQL 权限、管理员拒绝、NOLOGIN 与实例授权撤销、原文不可改、版本单调、四个并发发布者仅一个 CAS 成功，以及快照变化时拒绝旧游标/原文读。未知私有字段返回封闭错误。

真实 TOML 装配的原生 soxl-jev-api 在 PATH=/nonexistent 下读取持久化分页；停止并重启后游标保持；撤销数据库实例授权后相同 API 拒绝读取。没有启动 Python/Node、连接交易所或模型；夹具健康/模型明确 EXAMPLE_OR_MOCK，live_ready=false。

全模块 Go 测试、go vet、布局、离线 HTML/历史文档及 OpenAPI/Schema 检查通过，独立 API 构建通过。P3 与工具的 race 检查通过；没有 python/python3/pip/pip3/node/npm 的受控 PATH 下，P3/工程测试、构建和全部检查再次通过。GitHub 工作流上传需要 workflow 权限，CI 尚待补齐，不把本地验收标为 main 已交付。
