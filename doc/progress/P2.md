# P2 策略化框架层实现进度

更新时间：2026-10-05；已发布文档基线 v2.0.0。本轮完成 P2 实现和本地机制验收，P3 尚未实现。此次分类为 **code-only**：VERSION 保持 2.0.0，冻结的式样书、设计书、Word 和 releases.json 均未改动。

## 已实现范围

生产源码在 `src/factorforge/strategy`，按 domain/application/ports/adapters/api/workers 划分。独立 `factorforge-strategy` wheel 只打包框架及其迁移，依赖独立 P1 wheel；验收环境没有应用包。P2 不绑定交易对象、模型、联网采集或真实提示词，通过 P1 公共 HTTP 契约获取行情/账户/成交/保护并提交目标。P1 增加只读 owner/protection 查询和订单的目标版本投影；SIM 保护成交保留实际退出订单 ID，以便框架核对执行事实。

对象、经济事实版本与有来源评分、公共研究/内部执行资格、逐贡献衰减与价格兑现账本、周期决策/目标 outbox、噪声止损、组合风险投影、两个独立时段计数、实际成交案例/冻结观察窗、分层归因、独立 SIM 反事实、白名单固定步长学习及自动生效/回滚、因果时序验证和解释查询均已实现。生产使用 PostgreSQL，内存适配器用于确定性测试及提交失败注入。

开源参照先核对了9个项目45份文件；实际适配 Financier 多级滞回和 timeseriescv 严格时间清除算法，保留版权和完整 MIT 许可。其余项目提供流程参考；交易/撮合/账务直接复用 P1。详见 [复用记录](../engineering/P2_UPSTREAM_REVIEW.md) 与 [第三方声明](../../THIRD_PARTY_NOTICES.md)。

## 仍需外部业务验证的事项

本轮的参数、证据、标签与批准记录来自显式实验夹具，**没有标定任何生产常数，也没有证明收益、核心假设 H01～H08 或学习收敛**。研究验证框架记录不支持/未知结果和失败尝试；这类结果不能转换为生产升级许可。

生产使用仍须提供合法历史数据、可靠预期/价格证据、独立标注和样本组、事件量表/生命周期/价格代理标定，以及风险、费用、观察期、因子增量效果和学习发布的独立验证记录。关键参数为 REQUIRED_UNSET、评分不完整或价格不可用时保留研究/隔离状态并拒绝相关增险；不能用测试数值填补。

P3 的 SOXLUSDT、JEV、联网捕捉事件及私有提示词加载不在本轮。没有进行新的 Binance 测试网现场发单或生产实盘准入；P1 原有现场验收记录保持在 [P1 进度](P1.md)。
