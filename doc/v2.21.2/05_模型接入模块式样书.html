1 范围与继承

本模块为第三层独立模型接入，只做单轮文本生成：把私有提示词和上层给定的新闻文本发送给一个 OpenAI 兼容的 HTTPS 端点，返回候选文本。S5-001：不再提供交互式登录、OAuth 刷新、订阅账户池、模型目录发现和终端菜单；凭据只有操作者登记的一个 API Key。模块没有文件、命令执行、工具调用、交易、后台代理或自主循环权限。

模型输出仍是未核验候选文本，本模块不授予事实、事件、评分或交易资格。P3 新闻研判使用该输出时，资格由 P3 按其式样第 8 章与 P2 S2-039 授予；提示词由 P3 拥有并作为 system 文本传入。JEV 固定决策通道、暂停的抽取试验和本地模型保持原有边界。

v2.21.0 取代 v2.20.0 的 OMP 接入方式。替换理由与证据记录在设计书第 1 节：单供应商 API Key 场景下，OMP 的登录、账户池和目录能力未被使用，却带来 Bun 运行时、独立模型镜像和约 4,700 行 TypeScript 维护面。

2 通道与请求

S5-002：通道为单个 OpenAI 兼容端点。请求使用 POST，Authorization: Bearer <api_key>，Content-Type: application/json；正文包含 model、两条消息（system 为私有提示词，user 为渲染后的新闻文本）、response_format: {"type":"json_object"}、max_tokens 和可选的思考参数。

每次调用只允许一次请求：不自动重试、不切换模型、不切换端点、不回退到其他供应商。思考模式由配置决定；启用时按供应商支持的档位传递 thinking 与 reasoning_effort，不支持的参数不得伪造。请求不携带 tools，响应中的工具调用或推理型拒绝按失败处理。

3 调用与结果

S5-003：只有供应商明确正常结束、且 content 非空时才能返回。返回内容是纯文本，由 P3 的 ParseJudgment 继续做严格校验：JSON 对象、方向枚举、confidence 1–5、horizon 1–720 小时、所有引用 ID 必须来自本次输入。本模块不解析业务字段，也不修改上层提示词。

以下情况一律失败，不得作为成功结果：HTTP 非 200、finish_reason=length、空 content、缺少明确终态、拒绝或截断、工具调用、超时、断流。失败返回稳定错误码，不返回供应商原始错误正文、URL、身份或凭据。

单次调用的失败不自动重试。P3 按既有研判周期决定下一次调用；本模块不承担业务重放语义。

4 预算与去重

S5-004：本地预算按“请求次数 / 时间窗口”计，不按金额或 token 计。max_requests=0 表示不限次数；正数时 budget_window_seconds 必须为正数，达到上限即拒绝且不发送请求。默认建议 500 次 / 86400 秒，足够覆盖每日研判周期并保留约 5 倍余量；正常成本按实测约 2.5 元/天，上限只约束失控。

每次尝试前持久记录次数；失败不退占用。最近 256 个请求 ID 持久保存，窗口内重复 ID 不再发送；历史业务幂等仍由调用者负责。状态文件必须原子写、权限 0600、拒绝符号链接；时钟回退时拒绝调用。本地统计不代表供应商余额，供应商 429 或额度拒绝按失败返回。

5 边界与异常

S5-005：总开关、单次超时、输入字节上限、输出字节上限和 max_tokens 必须显式配置；任一缺失或非正数时模块不可用。输入超过上限不发送；输出超过上限或缺少终态判失败。

S5-006：错误分为调用边界错误与供应商错误。鉴权失败（401/403）不重试；限流（429）与 5xx 按失败返回，不自动换模型；网络错误、超时和断流报告投递不确定。所有错误信息不包含 Key、提示词或供应商正文。

6 私有资产与隔离

S5-007：真实 Key 只保存在被忽略的 config/config.toml；部署时为模型调用者派生只含 [model_access] 的私有文件，容器只挂载该文件，不挂整份主配置。日志、错误、测试报告和文档不得包含 Key、完整提示词或请求/响应正文。

模块不访问 P1/P2 私有实现或数据库，不启动交易，不读取其他程序的凭据目录。与 P3 的边界是 Go 接口调用，不再使用子进程或 JSONL 协议。

7 验收

编号验收
T5-01请求形状：端点、Bearer、json_object、max_tokens、思考参数与档位；不含 tools。
T5-02错误映射：401/403、429、5xx、超时、断流、非 JSON 信封分别返回稳定错误且不重试。
T5-03空 content、finish_reason=length、非法 JSON、工具调用、未知引用 ID 均判失败。
T5-04预算：0 不限可连续调用；正数上限拒绝且不发送；有限额无窗口判配置错误；失败不退占用。
T5-05去重跨重启生效；状态文件有界、0600、拒绝符号链接；时钟回退拒绝。
T5-06输入/输出字节上限、超时和 max_tokens 边界；超限不发请求或判失败。
T5-07日志与错误不含 Key、提示词或供应商正文；派生 model.toml 只含 [model_access]。
T5-08Compose：judgment-worker 使用 core 镜像、只挂派生文件；假端点时失败关闭。
T5-09显式人工授权后完成一次真实调用并记录结果；未执行时标注 REAL_CALL_PENDING。
T5-10离线 HTML 桌面与窄屏检查、正文迁移与配对检查。

隔离夹具与合成数据验收不等于真实供应商资格、P3 研判质量、年度成本或交易准入。真实调用必须由操作者显式授权，不能用测试自动触发。
