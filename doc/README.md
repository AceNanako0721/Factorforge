## 式样书与设计书

- **式样书**写原理和验收：系统应该做什么、为什么、边界在哪里，以及用什么场景验收。需求编号为 `S<层>-<序号>`，验收编号为 `T<层>-<序号>`。
- **设计书**写实现逻辑：代码结构、数据、接口、算法和测试。配置字段在描述用到它的逻辑时说明，字段名与代码完全一致；示例中的数值只示意格式。

两本书都只描述当前版本，不记录开发过程、实验或运行记录。
