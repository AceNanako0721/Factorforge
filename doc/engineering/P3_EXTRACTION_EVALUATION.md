# P3 抽取方法试验记录

日期：2026-10-09。试验先于 v2.1.6 设计和生产实现。

## 参考与试验范围

核对 TypeSafe 官方 [semantic_find](https://docs.typesafe.ai/cookbooks/semantic_find) 的稳定原文 ID、Choice 定位及独立 Noul 存在检查，以及 [预解析值抽取](https://docs.typesafe.ai/cookbooks/pre_parsed_value_extraction_cookbook) 的先枚举再原样回取。Choice 必有相对最佳选项，不能证明存在或支持；示例阈值不作为本项目生产常数。动态文档无固定源码提交；不复制代码、Prompt 或引入 Python。已有 SDK 协议参考仍为 MIT v0.6.0、66880ccded6cb642dc1809620c2b108c33730214 的 src/client.ts、src/types.ts。

新增可复跑的 opt-in Go 试验位于 tests/applications/soxl_jev/experiments/semantic_lab_test.go。普通测试跳过外部调用；仅显式指定私有实验目录时读取 config/config.toml 的 JEV Key，并按已冻结的私有请求做有限、无重试调用。实验不进入 worker，不修改业务配置或生产 Prompt，不调用下层写接口。真实指令、请求、原始响应和标签保存在忽略的 runtime/semantic-lab-20261009，目录 0700、文件 0600；公开代码没有实验 Prompt 正文。

## 实际结果与限制

固定 jev-1.13.0，12 个开发者制作的中英文合成对照，每次一个支持问题和一个事件关系问题；全部 HTTP 200。7729 输入、1031 输出 token；顺序请求 177～401 ms，账单费用 UNKNOWN。支持正例原始 Noul 为 0.93～0.97，负例为 0.01～0.04；这些仅是开发对照，不形成校准阈值或完整性证据。

关系最大概率选项 11/12 与开发标签一致。第 7 例目标为已经撤销的旧收入，支持 Noul=0.02，但关系仍选 RETRACTION（0.82），而不是依照“不支持则 UNKNOWN”的实验条件返回 UNKNOWN。原文明确撤销这一点不等于目标事实仍受支持；不能依靠 Prompt 约束或关系 Choice 单独授予事实资格。中文预测/更正、多主体、否定、相互矛盾、相对日期、原文指令注入及重复报道均有开发对照。

标签由同一开发者准备，实验模型未得到标签文件；这仍不是独立盲标。没有真实新闻、财经来源召回、完整事实枚举、长期延迟、收费或独立标定证据。12 次网络成功不证明生产抽取器准入，也不关闭 OD-01/OD-02。

## 方法决定

不将本轮模型关系选择直接接入生产。先完成已有人工/辅助抽取路径的可审查编译和摄入：完整原文自动准备 → 逐段显式审阅及原文跨度/事实/关系 → 确定性编译 Annotation 与 EventPlan → 现有核验、路由和框架接口。不能自动填审核身份、事实时间、权重、完整性或生产标定。

已失败抽取的原始 manifest 保持不可改。显式审阅产生独立且内容可重算的证据 ID，保留原始内容哈希及真实首次公开/接收时间，不能通过重新摄入刷新新鲜度。同一审阅重启保持同一 ID，不重复入队。新版私有文件只由 INGEST 加载；分析角色不读取原文审阅包。

下一项仍是具有独立标签、许可和保留集的语义抽取/事件关系评测，评测后再决定生产自动化。参数标定及前瞻证据属于 P4；DEC-06、人工应急和实盘授权属于 P5；不得据此将 P3 全部验收或 LIVE 准入标为通过。
