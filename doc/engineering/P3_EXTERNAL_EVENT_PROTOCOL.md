## 预先固定的抽样和投递

1. 下载固定文件，封存原始字节及 SHA256。只按原文选样：非空合法 UTF-8、原文 UTF-8 不超过 4096 字节；按原文字节 SHA256 升序，去重相同原文（保留文件中首个位置），取前八份。若不足八份或结构不能无损解读，中止，不临时换数据/样本；先记录格式问题并另行修订。筛选和排序不依据事件数、正确答案或模型响应。
2. 八份完整原句分别调用一次；其中前四份各增加一个空原文对照，共十二次 generate。空对照仍提供相同完整事件类型/角色定义，正文为空，不保留原文实体候选、触发词、标签或样本 UID。样本只使用本地生成的匿名请求 ID。
3. 固定 google-antigravity / account_id 1 / gemini-3.8-flash，顺序请求，不自动重试、修复 JSON、换模型或补样。单次 120 秒、输入 64 KiB、输出 32 KiB；这是有限开发试验的单次边界，模型接入本地总预算仍为 0（不限），不新增生产限额。网络/鉴权/投递未知停止后续请求并保留未完成；格式错误计失败，后续独立样本可继续。
4. 私有实验提示词在读取目标数据前创建并封存哈希，仅从 prompts 加载，不复制进仓库、本文或日志；不含任何目标样本、正确标签或据响应修订的示例。生产提示词和 semantic_extraction 开关不启用。仅试验 runner 临时调整既有模型接入非敏感边界，结束恢复原字段，保留 OAuth 刷新和持久调用统计。
5. 模型输入仅为完整原文、全部十类事件定义/角色定义及通用响应结构。标签另存，绝不作为请求字段、提示词或候选。下载/装配后、首次投递前封存输入、金标转换、全部代码/二进制/提示词哈希；后续变化使原轮失效，不覆盖旧轮。

## 本轮任务与预先固定的评分

这是比现有通用候选更细的实验性事件角色任务，不冒充生产 CompileSemanticCandidates 的验收：输出事件类型、原样触发词与 occurrence、若干 role/原样 quote/occurrence。occurrence 从零计，按相同非重叠原样字符串在完整原文中的出现次序定位。允许相同触发词对应多个独立事件；每个事件的角色必须绑定到该事件。不做单位换算、推断未表达日期或将当前试验角色接入 Claim/P2。

先无损校验上游标签：所有 span 均可按原始坐标回取原文；坐标制如为字符则显式换算 UTF-8 字节，不猜测、模糊查找或丢弃难例。重复、未知类型/角色或非法坐标必须保留为数据问题并中止准备；不能删掉再提高分数。角色全集从事件定义 PDF 建立，不从选中金标裁剪。任何格式适配在投递前记录并测试。

- 协议/字节支持：封闭 JSON、必需字段、无重复键、类型/角色合法、quote/occurrence 可精确定位；不自动去重。格式/跨度失败整份不计匹配，错误与原响应保留。
- 触发词：事件 type + 触发词绝对 UTF-8 span 多重集，重复预测消耗独立计数，报告 matched/missing/extra。
- 事件内角色：type + trigger span + role + argument span 多重集，报告 micro precision/recall/F1；不同事件的角色不拼装成一个正确事件。
- 完整事件：type + trigger span + 排序后的全部 role/span 多重集进行一对一完全匹配；缺一项、多一项、角色错配均失败。报告事件集合完全一致的句子数及 matched/missing/extra，不只列被选中的成功字段。
- 空原文：必须 events=[]；任何事件均为错误。空分母记 null，不写成 100%。未投递样本列 NOT_RUN，不能从计划分母消失。
- 分别报告日期角色与数额/数量/比例角色的匹配；原样 span 只能证明文字和角色对照，不能证明量级计算、经济效果、全文新闻完整性、否定/撤回或真实新鲜度。原始集合和标准评分不事后改口径。

记录耗时、完成状态、稳定错误码和所有封存哈希。当前 Go 公共端口未返回 token/cost，因此记 UNKNOWN，不估算。一次重复公开数据小样本只能发现反例；不设置未经标定的生产准确率阈值，不关闭 OD-01、OD-02、DEC-06 或 P3/LIVE。
