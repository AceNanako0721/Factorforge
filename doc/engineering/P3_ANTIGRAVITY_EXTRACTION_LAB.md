# Antigravity 语义候选试验

冻结日期：2026-10-11。用户授权最多 4 次生成请求、每次 120 秒、输入 64 KiB（含提示词）、输出 32 KiB。本试验独立于已暂停的本地模型试验，不使用其数据或提示词。试验结果不能作为独立盲测或 P3 交易准入证明。

## 调用前固定

- 唯一模型：账户模型目录实际返回的 `google-antigravity / gemini-3-flash`，账户 ID 1；不自动换模型、账号或重试。目录查询不计作生成请求。
- `tests/applications/model_access/experiments/semantic-cases.json` 为自有合成数据与预置期望值，包含多主体、多语言、否定、假设、修订、撤回及原文指令干扰。无真实配置、提示词或独立金标语料；公开源码按本仓库 MIT 授权。
- 逐段原文及主体/经济项目录提供给模型；期望值不提供给模型。响应只允许事件候选、原文引文、段落 ID、引文出现序号、目录 ID、断言语气、修订关系。要求单个 JSON 对象，禁止附加字段、代码围栏、工具或交易操作。
- `semantic-lab.ts` 在发送前以排他创建方式封存输入/请求/私有提示词哈希、模型、限制及时间。四个请求依次调用既有 `OMPService.handle`；预算先持久化再发送；失败停止，未知送达不重试。
- 仅临时打开私有集中配置的 OMP 生成边界，预算窗口固定为 24 小时，四次调用的总运行时间小于该窗口；不重置已存在预算。结束恢复原有开关和限制，保留凭据刷新及已消耗预算。信号退出也等待恢复和解锁。

## 预置观察项

每个请求分别记录：送达成功/错误码、耗时、响应字节与模型用量；严格 JSON/schema、所有候选的段落及原文精确匹配、已知目录 ID、重复候选、事件数及预置主体/经济项/语气/关系多重集合。UTF-8 原文跨度由程序计算，模型不产生可信字节偏移。原文引文必须来自指定段落，不能用 HTML 解码后的文本替代原始字节。

成功只能证明这四个合成例子的机制及语义候选表现；没有建立自动核验、事实完整性、生产成本/延迟标定、独立经济性或 JEV 评分能力。任何生产接入需先完成当前实例设计书；候选恒为 `REVIEW_REQUIRED`，只能经过既有明确审阅和核验流程进入后续链路。

## 结果

前三次 `gemini-3-flash` 均在约 3 秒内返回 `DELIVERY_UNKNOWN`。第三次观测：HTTP 200 / text/event-stream，192 字节、一个 SSE frame，response.candidates 仅有 content，缺少 finishReason；上游 error_id 135168，终止原因是缺少 finish reason。没有将 HTTP 200 计为模型调用成功，没有重试已发送案例。

第 4 次调用前修订：仍使用原先固定的 untrusted 合成输入、提示词及 schema，只将模型换为已发现的 `gemini-3.8-flash`，并使用新的请求 ID。排他创建 amendment-4.json 记录原请求哈希及修订原因；不把前三次失效的模型调用算作语义测试通过。不自动尝试更多模型。

原始报告保存在忽略的 runtime，公开记录只包含非敏感摘要和哈希。

第4次结果：`gemini-3.8-flash` 成功，7,878 ms，209 UTF-8字节，使用量 input=340/output=681/totalTokens=1021。严格JSON含1个候选，主体alpha、经济项revenue、AFFIRMED/UNKNOWN，引用p2的精确原文；与预置期望匹配，未将p1指令或p3导航文本作为事件。前三例因传输终态不完整没有语义结果，不能将其质量指标记为通过或零分。生成开关与所有临时边界恢复，4次持久占用保留。

用户随后要求本地次数预算默认不限；该规格修订独立按v2.5.0交付。旧v2.4.1为未发布草稿；接入设计已基于正式v2.5.0重新建立v2.5.1，第03设计书第23章与第05设计书candidate-integration定义公开协议、候选校验和审阅边界。设计先于生产实现提交。
