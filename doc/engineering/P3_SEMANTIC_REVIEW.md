# P3 语义候选与独立原文审阅

更新：2026-10-11；设计基线 v2.5.2。[第3本设计第24章](../v2.5.2/03_SOXLUSDT_JEV应用实例设计书.html#semantic-review-annotations)。

外部事件与衔接探针先通过 PR #50 进入 main `7a4c60f`，PR CI `38109948857`、main CI `38110194433` 各七项通过；设计提交 `e2086e0` 先于生产代码。五组业务式样语义保持，仅细化既有独立审阅的显示和校验。

`render-review` 可选 `--semantic-input`。旁注严格核对实例绑定、ProposalRequest 摘要、目录版本、请求记录与永久 attempt；按原始响应重编译候选，并在调用开始/完成的历史时点验证来源。当前过期材料可供历史审阅，不延长资格。哈希与 attempt 提供本地一致性检查，不是签名或来源真实性证明。

页面同时保留完整原文和未核验候选，显示断言/修订关系、段落锚点、UTF-8 字节跨度及原文引用；调用记录与哈希可展开。候选不预填人工事实，不构造评分或完成审阅；空候选不表示无事件。页面无脚本、外部资源、输入表单或发送动作。

参数示例（合为一条命令，路径与字节边界由操作者填写）：

```text
instance-cli --action render-review
  --proposal-input runtime/<原文审阅包>.json
  --semantic-input runtime/<语义候选>.json
  --proposal-output runtime/<新审阅页>.html
  --max-proposal-bytes <显式输入与页面字节边界>
```

输入均为私有运行文件，语义候选旁边必须保留同名 `.attempt`。不加载配置、真实提示词、Bun、数据库或模型，不调用 JEV/P2/P1；输出必须是新文件。不给可选参数时保留原工作流。记录不符、未知字段、权限/链接/大小/时间异常均拒绝，无不完整页面或静默回退。

验证包括：正常/空/否定/修订显示，HTML 注入与本地锚点，输入字节不变、0600 与禁止覆盖；绑定/目录/摘要/候选重编译/attempt/时间/未知字段/符号链接/权限/路径/大小拒绝；过期历史材料可读；缺少配置与 Bun 的实际 CLI 仍可生成页面。既有真实三候选产物也经过桌面和窄屏浏览器检查，无外部网络请求。机制通过不代表候选质量通过。

用户已明确选择继续完善无人值守抽取与独立评测，暂不启用生产。人工逐批审阅不是最终方案；此页用于开发诊断和现有独立审阅能力。接下来继续外部独立标签、单位/时间范围和事件完整性的验证，保留既有失败指标，不据显示改进提升生产资格。本地大模型实验保持停止。
