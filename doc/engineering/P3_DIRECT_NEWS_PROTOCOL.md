# P3 JEV 新闻原文直评试验协议

2026-10-11；用户授权的 code-only 方法试验，基线 v2.5.2。本文先于完整正文获取、问题封存和模型投递提交。不是生产方法定稿，不修改 S3-006 的独立事实核验、事件身份、去重、更正或准入要求。

## 问题与比较边界

验证新闻正文作为 JEV `state` 能否直接支持有限的相关性、方向、状态和事件粒度判断，从而减少独立字段抽取的需要。官方 [API](https://docs.typesafe.ai/api) 允许 state 为文本/对象，返回 Choice、Score、Noul；问答 ID 不参与推理。复用既有 `TestJevSemanticMethodProbe` 的单次 HTTP 投递机制，不调用生产 JevHTTP、模型接入网关、JEV 以外模型、数据库或下层。

本轮是原文直评基线，比较对象为已知语义的控制对照、同输入重放及有上下文的重复/更正；不是同批“抽取后评分”优劣试验，不与 FewFC 完整事件 0/8 合并或换算。历史公开材料可能被训练见过；自编控制和开发者判读不是独立人工盲标。真实市场方向、影响幅度、收益及概率校准没有金标。

## 样本固定

先固定四份完整官方正文 URL；已通过搜索看到标题/片段，不能称未见材料。获取失败记录失败，不临时换文章。HTML 仅去导航、脚本、样式并转为可读正文；保留文章标题、全部正文、列表、表格和限定，不能摘取成功句、摘要或截断。获取字节/正文哈希、解析根、正文范围和时间另存私有 manifest。超过 2 MiB HTML 或单次 64 KiB 请求则记录不能运行，不能缩短。

1. NVIDIA FY2026 Q1 财报：https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-first-quarter-fiscal-2026
2. NVIDIA H20 许可/恢复销售公告：https://blogs.nvidia.com/blog/nvidia-ceo-promotes-ai-in-dc-and-china/
3. FOMC 2025-09-17 声明：https://www.federalreserve.gov/newsevents/pressreleases/monetary20250917a.htm
4. NASA Webb 行星新闻：https://science.nasa.gov/missions/webb/nasas-webb-images-young-giant-exoplanets-detects-carbon-dioxide/

另有八个自编合成控制：明确已发生正向经营变化、反向变化、否定发生、未来计划、正反混合、更正旧文、无关正文、空正文；两个中英对应控制；财报同请求独立重放一次；正向控制以同内容作为前文的重复一次，共十六次。每项最多一次，重放是预定独立试验项而非错误重试。所有标签和允许答案集合在首个请求前封存，不在看响应后改动。

## 模型输入与评价

固定 `jev-1.13.0`，state 仅为正文及可空的前文。目标与判断规则全部来自私有 questions 文件；不发送期望答案、类别标签、抽取候选、摘要、Claim、账户、仓位、URL 或原始配置。目标是美国半导体行业的经营/政策信息，不推断 SOXLUSDT 合约价格或交易方向。正文按不可信资料处理。

六个固定问题：相关性（直接/宏观/无关/未知）、正文所述行业基本面方向（正/负/混合/中性/不足）、已发生/计划/否定/混合/不足、可独立维护的目标事件数类别（一个/多个/无/未知）、相对前文关系（新增/重复/更正/无法判断），以及五级影响内容分数。五级分数只作描述，不能映射到 P2 矢量或宣称校准。

- 协议：HTTP、精确模型、全部六题/类型、概率分布、合法选项/数值及有限用量逐项校验；格式成功与业务判断分开。
- 分类：真实四题和合成控制分开，按封存的可接受答案集合逐题比较，同时报告原始选项、错误和分母。边界不确定的真实字段在调用前明确不评分；禁止事后扩展集合。
- 影响：仅列原始 score/分布及已定义的正负、无关和空文对照；没有人工业务量表，不报告影响准确率、不挑生产阈值。
- 空/否定/计划：检查是否区分无证据、否定发生和未来状态；分类判断不等于真实性核验。
- 重复/更正：只验证已提供前文时的关系判断；无前文返回无法判断是有效选择。不证明全库检索、跨来源实体关联或 P2 幂等。
- 同输入重放：报告分类一致数和分数差，不设“稳定通过”阈值。

## 投递、保存与结论边界

十六个请求、20 秒/次、请求/响应各 64 KiB，为本轮实验停止条件，不写入全局配置或生产默认预算。本地模型预算保持默认不限；canonical config 只读。单并发、无跳转、无自动重试/切换模型；网络未知/非200/协议失败停止，全部计划项保留 NOT_RUN。首调用前保存 questions、源文件、state、标签、请求、比较器和 runner 的 SHA256；started 标记永久禁止误重投。真实 Key 只从被忽略 config/config.toml 在内存加载，不进入产物。

源码只在 tests/applications/soxl_jev/experiments；真实指令、正文、标签、请求/响应和原始评价保存在忽略 runtime 下的0700目录/0600文件。公开仅方法、来源、哈希和聚合/自有有限诊断。公司文章不再分发，不把研究获取当作生产许可登记。

结果先说明原文直评可做什么、失败在哪里；不得把一次文章评分当作逐事件事实、自动核验或完整 P3。若选定生产方法，先判断是否改变事件粒度/事实要求，必要时先修订式样，再配对 HTML 设计，最后实现。保持生产关闭、本地模型暂停及全部既有工作。

## 获取方法修订（模型调用前）

首轮直接复用生产 Fetcher 时，在第一份正文网络获取处失败，零正文/零模型调用；原 acquisition-started/failed 永久保存在 runtime/jev-direct-news-lab-20261011。同 URL 的独立 HEAD 得到200，尚未定位直接连接与环境代理/地址族的具体差异。仅将实验获取改为系统 HTTP transport（允许已有 HTTPS 代理），仍固定上述四个 HTTPS URL、拒绝跳转、20秒和2MiB。另建 v2 私有实验目录，不删除或覆盖失败轮；生产 Fetcher/SSRF/来源准入不变。此为明确记录后的新获取尝试，不是模型重试，也不表示生产采集问题已修复。

v2 的首个 Go GET 返回403，仍零正文/模型；独立 curl GET 同 URL 为200/364956字节。原因尚未细分为客户端指纹/代理/HTTP版本，不声称已定位。最终仅实验获取使用开发机已有 curl，固定HTTPS URL、无-L/无重试、20秒/2MiB；新 v3 目录保留前两轮。curl只属于显式源码采集试验，不成为生产、构建或普通测试必需依赖；离线测试无外部调用。
