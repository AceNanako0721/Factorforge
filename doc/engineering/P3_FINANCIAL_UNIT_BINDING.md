## 明确不能由坐标证明的部分

新增离线反例同时给出一个数值和包含 thousand、但明确排除该数值类型的表头：数值坐标存在、单位坐标存在、单位词与 scale 拼写一致，三个机械条件仍都成立。这说明旁边的有效单位证据可能不适用于该数值；不能因此自动形成已核验 Claim、Complete 或交易资格。移除单位表头时，单位坐标检查可拒绝，数值支持仍保留，验证二者独立。

真实样本里也出现排除每股数据的限定表头；模型本次所选答案符合外部 scale，但机械原型本身没有理解该排除条件。下一轮应冻结单位适用范围、期间、主体/指标及相邻/例外误绑定对照，验证它们和数值、单位 ID 的完整关系。当前有限选择可作为审阅辅助候选方法继续研究；如接入生产，仍须先完成对应 HTML 设计，保持下层和已审阅生产链路的资格边界。

普通测试覆盖单位排除范围的反例及单位移除；相关 P3/工程测试、实验 race、定向 vet、布局与 code-only 基线冻结检查通过。后处理再次按固定源文件 SHA 及 question UID 核对答案/scale/source，原始证据的只读副本重评仍为4/4，没有新供应商调用，也没有覆盖原报告。历史公开数据污染、独立未见新闻、全篇/事件完整性、正式评分/标定、来源组合、OD-01/OD-02 及 P3 整体验收继续未关闭。
